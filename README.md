# مدار — استوديو رقمي إبداعي

موقع كامل لشركة إبداعية، مبني بـ HTML/CSS/JavaScript خالص **بدون أي اعتماديات خارجية** ولا خطوة بناء.
التصميم والتجربة مستوحيان من مواقع الاستوديوهات الحديثة، والمحتوى والنصوص والهوية أصلية بالكامل.

---

## التشغيل

### الطريقة الأسرع
افتح `index.html` مباشرة بالنقر المزدوج. كل شيء يعمل — لا وحدات ES ولا `fetch`، لذا لا يحتاج خادمًا.

### عبر خادم محلي (مستحسن للتطوير)
```bash
powershell -ExecutionPolicy Bypass -File serve.ps1
```
ثم افتح <http://localhost:5177/>

لتغيير المنفذ: `-Port 5178`

> خادم بسيط مبني على `System.Net.HttpListener` — لا يحتاج Node ولا Python.
> الملف مكتوب بمحارف ASCII فقط لأن Windows PowerShell 5.1 يقرأ `.ps1` بترميز ANSI ويتعطّل مع العربية.

## محرك الحركة

كل ما يلي مكتوب من الصفر في `js/app.js` — لا GSAP ولا Lenis ولا jQuery:

| الوحدة | ما تفعله |
|---|---|
| **Ticker** | حلقة `requestAnimationFrame` واحدة تغذّي كل الوحدات |
| **Scroll** | تمرير ناعم باستيفاء على التمرير الأصلي — لذلك تبقى `position:sticky` و`IntersectionObserver` تعمل طبيعيًا |
| **Cursor** | مؤشر مخصص بخمس حالات: `pointer` · `text` · `media` · `hidden` · `drag` |
| **Reveal** | تقسيم النص إلى أسطر مع كشف متتالٍ، وظهور بالتلاشي أو بالقصّ |
| **Marquee** | شريط لانهائي تتغيّر سرعته بسرعة التمرير |
| **Magnetic** | عناصر تنجذب نحو المؤشر |
| **Parallax** | إزاحة محسوبة على موضع العنصر في الإطار |
| **Feature** | قسم لاصق تتبدّل صورته مع القسم النشط |
| **Transition** | ستار انتقال بين الصفحات بلا وميض |
| **Drag** | سحب أفقي بالمؤشر أو باللمس أو بالعجلة |

### تفاصيل تقنية تستحق الانتباه

**التمرير الناعم لا يحرّك حاوية.** الطريقة الشائعة (`transform` على عنصر لاف) تُبطل `position:sticky` لأن لا شيء يتمرّر فعليًا. هنا نعترض العجلة، نجمع الهدف، ثم نستدعي `window.scrollTo` بقيمة مستوفاة كل إطار — فيبقى التمرير أصليًا.

**اتجاه RTL يعكس اتجاه الفيض.** في `dir="rtl"` يفيض المحتوى الأفقي يسار الإطار لا يمينه، لذا الإزاحة الموجبة هي التي تسحبه إلى الداخل. هذا يخصّ الشريط المتحرك وقائمة الاقتباسات.

**تقسيم النص يحترم تشكيل الحرف العربي.** التقسيم يتم على مستوى الكلمة لا الحرف — تقسيم الحروف يكسر الاتصال بينها.

**لا `overflow:hidden` على `html`/`body`.** يُبطلها `position:sticky`؛ استُخدم `overflow-x:clip` بدلًا منها.

**الحركة تُعطَّل** تلقائيًا مع `prefers-reduced-motion`، والمؤشر المخصص والتمرير الناعم يُعطَّلان على أجهزة اللمس.

## التخصيص

### الألوان والمقاسات
كل الرموز في أول `css/style.css` تحت `:root` — الألوان، المسافات، أحجام الخط، أنصاف الأقطار، ومنحنيات التوقيت.

### الصور
لا يحتوي المشروع صورًا. البدائل البصرية `.md-poster` مولّدة بـ CSS عبر أربعة متغيّرات لونية:

```html
<div class="md-poster" style="--c1:#1b1a2e;--c2:#6b5cff;--c3:#b9aeff;--c4:#0a0a0a"></div>
```

لاستبدالها بصور حقيقية: ضع `<img>` داخل نفس الحاوية واحذف `.md-poster`. الحاويات مضبوطة أصلًا بـ `overflow:hidden` ونسبة أبعاد.

### الخط
`IBM Plex Sans Arabic` من Google Fonts، مع تدرّج احتياطي (`Segoe UI` ثم `Tahoma`) يعمل بلا إنترنت.
للعمل دون اتصال بالكامل: نزّل الخط إلى `assets/fonts/` واستبدل رابط `<link>` بقاعدة `@font-face`.

### إضافة صفحة
انسخ أقرب صفحة قائمة، غيّر `data-page` على `<body>`، وحدّث الروابط في الترويسة والقائمة والتذييل.

## نقاط مفتوحة

- **نموذج التواصل واجهة فقط.** لا يوجد خلفية؛ الإرسال يعرض رسالة تأكيد ولا يرسل شيئًا. يحتاج ربطًا بخدمة نماذج أو نقطة نهاية خاصة بك.
- **المدونة والمشاريع محتوى ثابت.** روابط المقالات والمشاريع تشير إلى `blog.html` و`project.html` كنماذج. الربط بنظام إدارة محتوى خطوة تالية.
- **لم تُختبر الحركات بصريًا** في بيئة البناء (لم يتوفّر متصفح يرسم إطارات). تحقّق من التخطيط والقياسات حسابيًا على الصفحات السبع، لكن التحقق البصري من الإيقاع والتوقيت يحتاج فتح الموقع في متصفحك.

## الدعم

آخر إصدارين من Chrome و Edge و Firefox و Safari.
تُستخدم `:has()` و`overflow:clip` و`color-mix()` — جميعها مدعومة في المتصفحات الحديثة، وتتدهور بلطف إن لم تُدعم.
