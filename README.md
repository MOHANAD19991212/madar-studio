# نون الاحترافية — Noon Professionals

موقع الشركة، مبني بـ HTML/CSS/JavaScript خالص **بدون أي اعتماديات** ولا خطوة بناء.
الهوية البصرية (الشعار، الألوان، الخطوط) مطبّقة من دليل العلامة الرسمي.

---

## التشغيل

### الأسرع
افتح `index.html` بالنقر المزدوج. لا وحدات ES ولا `fetch`، فلا يحتاج خادمًا.

### عبر خادم محلي (مستحسن)
```bash
powershell -ExecutionPolicy Bypass -File serve.ps1
```
ثم <http://localhost:5177/> — لتغيير المنفذ: `-Port 5178`

> خادم على `System.Net.HttpListener`، لا يحتاج Node ولا Python.
> الملف بمحارف ASCII فقط لأن Windows PowerShell 5.1 يقرأ `.ps1` بترميز ANSI ويتعطّل مع العربية.

## الهوية البصرية

### الألوان
مأخوذة حرفيًا من دليل العلامة، ومعرّفة في `:root` أعلى `css/style.css`:

| الرمز | القيمة | الاستخدام |
|---|---|---|
| `--ink` | `#231f20` | النص الأساسي (ثانوي العلامة) |
| `--inv-bg` | `#000000` | الأقسام الداكنة (أساسي العلامة) |
| `--accent` | `#24baa9` | التيل — لون العلامة الأساسي |
| `--accent-2` | `#4dbd99` | الأخضر — أساسي ثانٍ |
| `--muted` | `#404041` | رمادي ثانوي |
| `--brand-grad` | `#24baa9 → #4dbd99` | التدرّج الرسمي |

كل اللوحات البصرية في الموقع (٦٨ لوحة) مشتقّة من هذه الألوان حصرًا.

### الشعار
`assets/brand/noon-mark.svg` — النسخة المضغوطة (V2) للترويسة
`assets/brand/noon-lockup.svg` — اللوحة الكاملة (V1) لشاشة التحميل

يُرسم الشعار كـ **قناع** (`mask`) فوق `currentColor`، لا كصورة:

```css
.md-logo__mark{
  background-color:currentColor;
  mask:url("../assets/brand/noon-mark.svg") center/contain no-repeat;
}
```

ولهذا يقلب لونه تلقائيًا من الأسود إلى الأبيض عند مرور الترويسة فوق قسم داكن، بملف واحد وبلا تضمين SVG في كل صفحة.

النسخ الأصلية كاملةً محفوظة في `assets/brand/V1__*.svg` و`V2__*.svg`.

### الخطوط
`itf Ghroob Arabic` — يغطّي العربية واللاتينية معًا حسب الدليل.

| الوزن | القيمة | الاستخدام |
|---|---|---|
| Light | 300 | التفاصيل الصغيرة |
| Regular | 400 | النصوص العامة |
| Medium | 500 | الفقرات الوصفية |
| Bold | 600–700 | العناوين الفرعية |
| ExtraBold | 800 | العناوين البارزة |

> **⚠️ تنبيه ترخيص:** ملفات `.otf` في `assets/fonts/` هي ملفات **سطح مكتب**. تضمينها في موقع عام يحتاج عادةً **ترخيص Webfont منفصلًا** من الناشر (International TypeFounders). راجع عقد شرائك قبل النشر.
>
> لتقليل الحجم لاحقًا: حوّلها إلى `.woff2` (توفّر ~٦٠٪) واستبدل `format("opentype")` بـ `format("woff2")` في أعلى `style.css`.

## فيديو الواجهة

`assets/video/showreel.mp4` — 1920×1080 · ٥٠ ثانية · ١.٧٢ ميجابت/ث · **١٠.٧ ميجابايت**

### تشغيل تلقائي مشروط

الفيديو **لا يُحمَّل للجميع**. القرار في `autoAllowed()` داخل `js/app.js`:

| الحالة | السلوك |
|---|---|
| حاسب + اتصال `4g` فأعلى | تشغيل تلقائي صامت بحلقة |
| جوال أو شاشة < 820px | لا تحميل — لوحة ثابتة وزرّ «تشغيل» |
| `saveData` مفعّل | لا تحميل |
| `2g` / `3g` | لا تحميل |
| `prefers-reduced-motion` | لا تحميل |

**المصدر في `data-src` لا `src`** — وهذا جوهري: المتصفح يبدأ التحميل بمجرّد قراءته لـ `src` في الترميز، أي قبل أن يعمل الجافاسكربت أصلًا، فتضيع فائدة الشرط كاملة. الجافاسكربت هو من يضبط `src` بعد اتخاذ القرار.

تحقّقت: على عرض 375px يبقى `video.readyState === 0` — **لم يُطلب بايت واحد**.

### الزرّ الأوسط — ثلاث حالات
- قبل البدء: **تشغيل** (مثلّث)
- يعمل ومكتوم: **الصوت** (سمّاعة مشطوبة)
- يعمل بصوت: **كتم** (سمّاعة بموجات)

الكتم إلزامي في التشغيل التلقائي — كل المتصفحات تمنعه مع صوت. أما النقر اليدوي فإيماءة صريحة تسمح بالصوت مباشرة.

يتوقّف الفيديو تلقائيًا حين يخرج من الشاشة.

### ⚠️ لتخفيفه فعليًا: اقصص لا تضغط
الترميز مقتصد أصلًا (١.٧٢ ميجابت/ث عند 1080p ترميز ممتاز). خفض معدل البت سيُفسد الصورة. المدة هي المشكلة:

```
١٢ ثانية × ١.٧٢ ميجابت/ث ÷ ٨ = ٢.٦ ميجابايت — بنفس الجودة تمامًا
```

```bash
ffmpeg -i showreel.mp4 -ss 0 -t 12 -c copy -movflags +faststart loop.mp4
```

`-c copy` = قصّ بلا إعادة ترميز ⇒ صفر خسارة. حينها يمكن تشغيله تلقائيًا للجميع وإلغاء الشرط.

> `faststart` مفعّل في الملف الحالي (`moov` قبل `mdat`)، ولذلك يبدأ التشغيل خلال ثانية ولا ينتظر التحميل الكامل.

## محرك الحركة

مكتوب من الصفر في `js/app.js` — لا GSAP ولا Lenis ولا jQuery:

| الوحدة | ما تفعله |
|---|---|
| **Ticker** | حلقة `requestAnimationFrame` واحدة تغذّي كل الوحدات |
| **Scroll** | تمرير ناعم باستيفاء على التمرير الأصلي |
| **Cursor** | مؤشر مخصص بخمس حالات |
| **Reveal** | تقسيم النص إلى أسطر وكشف متتالٍ |
| **Marquee** | شريط لانهائي يتأثر بسرعة التمرير |
| **Magnetic** | عناصر تنجذب نحو المؤشر |
| **Parallax** | إزاحة محسوبة على موضع العنصر |
| **Feature** | قسم لاصق تتبدّل صورته |
| **Transition** | ستار انتقال بين الصفحات بلا وميض |
| **Drag** | سحب أفقي بالمؤشر أو اللمس أو العجلة |

### تفاصيل تقنية تستحق الانتباه

**التمرير الناعم لا يحرّك حاوية.** الطريقة الشائعة (`transform` على عنصر لاف) تُبطل `position:sticky`. هنا نعترض العجلة ونستدعي `window.scrollTo` بقيمة مستوفاة كل إطار، فيبقى التمرير أصليًا.

**RTL يعكس اتجاه الفيض.** في `dir="rtl"` يفيض المحتوى الأفقي يسار الإطار، فالإزاحة الموجبة هي التي تسحبه إلى الداخل.

**إحداثيات الفأرة فيزيائية دائمًا.** مواضع المؤشر وزرّ التشغيل وزرّ القائمة تستخدم `top/left` لا `inset-inline-start` — لأن `translate(-50%)` فيزيائي، واستخدام خاصية منطقية معه يزيح العنصر بعرضه كاملًا في RTL.

**تقسيم النص على مستوى الكلمة** لا الحرف، حفاظًا على اتصال الحروف العربية.

**لا `overflow:hidden` على `html`/`body`** لأنه يُبطل `position:sticky`؛ استُخدم `overflow-x:clip`.

**الحركة تُعطَّل** مع `prefers-reduced-motion`، والمؤشر والتمرير الناعم يُعطَّلان على أجهزة اللمس.

2. **بيانات التواصل مؤقتة:** `info@noonprofessionals.com` · `jobs@noonprofessionals.com` · `+966 50 000 0000` · العنوان. استبدلها بالحقيقية.
3. **نموذج التواصل واجهة فقط** — لا يرسل شيئًا. يحتاج ربطًا بخدمة نماذج أو نقطة نهاية.
4. **اسم المجلد والمستودع** ما زال `madar-studio`.
5. **ترخيص الخط** — انظر التنبيه أعلاه.
